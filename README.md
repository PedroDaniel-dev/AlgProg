# Sistema de Cadastro de Clientes — Maison du Chocolat

Este projeto foi desenvolvido como parte da disciplina de Algoritmos e Programação, no primeiro período do curso de Sistemas de Informação da UNIRIO.

O sistema simula o cadastro e gerenciamento de clientes de uma loja fictícia chamada *Maison du Chocolat*, permitindo armazenar e consultar informações básicas de clientes.

---

## Sobre o projeto

Este foi meu primeiro projeto na graduação, com foco no aprendizado de lógica de programação utilizando a linguagem C.

O sistema funciona via terminal e permite cadastrar, validar e consultar dados de clientes, aplicando conceitos fundamentais da programação.

---

## Funcionalidades

- Cadastro de clientes com validação de dados:
  - Nome completo  
  - CPF (com verificação de dígitos e duplicidade)  
  - Data de nascimento  
  - Telefone (com tratamento de DDD)  
  - Email  

- Busca de cliente por CPF  

- Listagem de aniversariantes por mês  
  - Ordenados pelo dia de nascimento  

- Atualização automática de cliente já cadastrado (mesmo CPF)

---

## Conceitos aplicados

- Estruturas (`struct`)
- Vetores (arrays)
- Funções
- Validação de entrada de dados
- Manipulação de strings (`string.h`)
- Estruturas condicionais e de repetição
- Ordenação (Selection Sort)
- Modularização do código
